# Участие в разработке

## Перед началом

1. Прочитайте [быстрый старт](docs/QUICK_START.md) и
   [контракт биндингов](docs/BINDING_CONTRACT.md).
2. Убедитесь, что установлен Godot 4.7.x и доступен PowerShell 7 или Windows PowerShell 5.1.
3. Выберите тему через `Редактор → Выбрать тему` и редактируйте только её
   `themes/<id>/package/`.
4. Если работает ИИ-агент, он обязан следовать [AGENTS.md](AGENTS.md).

## Внесение изменений

- Одна задача должна менять один понятный аспект темы или tooling.
- Не меняйте binding-id, канонические имена сцен и package-копию контракта вручную.
- Скрипты и runtime-узлы темы разрешены. Не переносите в тему код оплаты, COM-контроллер и
  остальные app-owned подсистемы без отдельного изменения host-контракта.
- Исходные материалы, лицензии и референсы храните в `source/`; оптимизированные runtime-копии —
  только в `package/`.
- Новый видимый текст пишите по-русски, понятно для владельца автомата. Используйте «промо» и
  «промо-ролик».

## Проверка изменения

```powershell
.\tools\Test-PackagedBindingContract.ps1
.\test-theme.ps1 -ThemeId space-pixel
.\build-theme.ps1 -ThemeId space-pixel
```

После автоматических проверок просмотрите все девять вкладок preview при `720×1280`, сначала без
overlay, затем с `BINDINGS: ON`. Полный checklist находится в
[документе QA](docs/QA_AND_TROUBLESHOOTING.md).

Команда сборки с `-InstallToDefaultUserPath` заменяет установленный PCK Exchanger. Запускайте её
только осознанно.
