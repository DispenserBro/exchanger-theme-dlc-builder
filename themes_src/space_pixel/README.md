# Архив исходников темы `space_pixel`

> Этот каталог относится к ранней partial-theme модели и не является источником разработки.
> Актуальные материалы находятся в `themes/space_pixel/source/`, production-пакет — в
> `themes/space_pixel/package/`, формат — `ExchangerThemeDlc` v2.

Этот каталог содержит оригинальные материалы темы и не включается в DLC напрямую.
Исходные файлы не удаляются и не перезаписываются при подготовке пакета.

Фактическая структура поставки сохранена: UI-файлы лежат в корне, последовательности кадров —
в русскоязычных подпапках, шрифт — в `Шрифты/`. Производные копии получили ASCII-имена и лежат
отдельно в `res://exchanger_theme_dlc/assets/`.

В `references/` локально скопированы восемь макетов интерфейса, рендер корпуса разменника и
видео полного пользовательского потока. Этот каталог нужен только для визуального сравнения,
игнорируется Git и не экспортируется в DLC.

Обязательные правила Exchanger:

- основной фон остаётся статическим;
- анимация реализуется отдельными спрайтами в пассивной decoration-сцене;
- шейдеры, частицы и видео для фона не используются;
- тема должна корректно работать при отключённой decoration-сцене (`ReducedEffects=true`);
- исторические runtime-ресурсы отсюда не собираются; актуальная тема использует
  `themes/space_pixel/package/` и `ExchangerThemeDlc` версии 2.

Поставка содержит 46 PNG и один шрифт `VCR OSD Mono Cyr.ttf`. Файл `Цвета.txt` имеет нулевой
размер, поэтому палитра темы определена по самим изображениям. Файлы `.import` и `Thumbs.db`
считаются метаданными исходной поставки и не копируются в runtime-каталог.
