# Исходники темы `space-pixel`

Этот каталог содержит оригинальные материалы темы и не включается в DLC напрямую.
Исходные файлы не удаляются и не перезаписываются при подготовке пакета.

Фактическая структура поставки сохранена: UI-файлы лежат в корне, последовательности кадров —
в русскоязычных подпапках, шрифт — в `Шрифты/`. Производные runtime-копии получили ASCII-имена
и лежат отдельно в соседнем `package/assets/`.

В `references/` локально скопированы восемь макетов интерфейса, рендер корпуса разменника и
видео полного пользовательского потока. Этот каталог нужен только для визуального сравнения,
игнорируется Git и не экспортируется в DLC.

Обязательные правила Exchanger:

- основной фон остаётся статическим;
- анимация реализуется отдельными спрайтами в пассивной decoration-сцене;
- шейдеры, частицы и видео для фона не используются;
- тема должна корректно работать при отключённой decoration-сцене (`ReducedEffects=true`);
- итоговые runtime-ресурсы помещаются в соседний `package/`, напрямую отображаются в preview и
  собираются в пакет `ExchangerThemeDlc` версии 2 с каноническими runtime-путями.

Исходная UI-поставка включает `tumbler_on.png`, `tumbler_off.png`, `button_up.png`,
`button_down.png`, новые пиктограммы питомца `home.png`/`cross.png` и исходные дубликаты
последовательности мытья `climbing_action_start.png`/`climbing_action.png`/
`climbing_action_stop.png`, а также один шрифт
`VCR OSD Mono Cyr.ttf`. Дополнительный каталог
`alien_animation/` содержит 22 sprite-sheet интерактивного питомца; это сохранённое имя папки
исходной поставки конкретной темы, а не требование builder. Production-сцена
`package/components/interactive_pet.tscn` ссылается на свои runtime-копии напрямую и использует
414 кадров по сетке `128×128 px`. Другие темы могут хранить текстуры питомца в папке с любым
именем — переименование под `alien_pet` не требуется. Исходные стрелки `64×64 px`
преобразуются в runtime-копии `32×32 px` ближайшим соседом, чтобы целиком помещаться в две
половины `SpinBox`. Файл `Цвета.txt` имеет нулевой
размер, поэтому палитра темы определена по самим изображениям. Большинство файлов `.import` и
`Thumbs.db` считаются метаданными исходной поставки и не копируются в runtime-каталог. Для
production-шрифта отдельно поддерживается `package/assets/fonts/vcr_osd_mono_cyr.ttf.import`:
он отключает antialiasing, hinting и subpixel positioning и фиксирует oversampling `1.0`.

## Происхождение шрифта

Встроенные metadata исходного TTF: family `VCR OSD Mono [RUS by Daymarius]`, version
`1.00 August 17, 2018`, designer `MrManet`. Поля copyright, license и license URL пусты.

- автор оригинального VCR OSD Mono подтвердил бесплатное коммерческое использование в комментарии
  на `https://www.dafont.com/font-comment.php?file=vcr_osd_mono`;
- точная кириллическая версия описана сторонним каталогом
  `https://ffont.ru/en/font/vcr-osd-mono-rus-by-daymarius`, но эта страница не заменяет разрешение
  автора модификации.

Для внутреннего проекта файл сохраняется ради совпадения с референсами. Перед публичным
распространением PCK нужно получить письменное разрешение Daymarius либо заменить TTF на шрифт с
явной лицензией и заново выполнить pixel-perfect QA всех экранов.
